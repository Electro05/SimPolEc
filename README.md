# SimPolEc

Симулятор экономики государства с живым рынком, сословиями и реальным временем.

Бунга Унга — крестьянская страна, в которой нет ни одного завода. Хлеб растят
крестьяне, одежду и мебель шьют и строгают кустари, горожане живут торговлей и
ремеслом. Ни рудников, ни металлургии, ни станков: инструментов и электроники
в стране просто нет. Вы — промышленник, и первый завод здесь будет вашим.

Каждые 15 минут происходит **пейдей** — экономика делает шаг: заводы
переманивают людей из деревни, крестьяне снимают урожай, кустари берутся за
самое выгодное ремесло, население тратит заработанное, пересчитываются цены.

## Запуск

Зависимостей нет — нужен только Python 3.10 или новее.

```bash
python run.py
```

Откройте http://127.0.0.1:8000, придумайте имя и пароль — и вы в игре.

Для отладки удобно ускорить время:

```bash
SIMPOLEC_TICK=5 python run.py     # пейдей раз в 5 секунд
```

На Windows (PowerShell):

```powershell
$env:SIMPOLEC_TICK=5; python run.py
```

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `SIMPOLEC_TICK` | длина пейдея в секундах | `900` |
| `SIMPOLEC_AUTOTICK` | `0` — не тикать по таймеру, только кнопкой | `1` |
| `SIMPOLEC_DB` | файл базы | `simpolec.db` |

Мир сохраняется в SQLite и переживает перезапуск. Чтобы начать заново —
удалите `simpolec.db`.

## С чего начать играть

1. Откройте вкладку **Население**. Там написано, сколько человек зарабатывает
   в деревне — это ваша планка. Платить меньше бессмысленно: никто не придёт.
2. Вкладка **Строительство**. Смотрите не только на прибыль с работника, но и
   на столбец «сырьё». Завод, построенный раньше своей сырьевой базы, будет
   стоять и жечь деньги.
3. Начинать почти всегда стоит с того, что деревня уже даёт: лес, зерно, хлопок
   лежат на рынке дёшево. Лесопилка и ткацкая фабрика окупаются сразу.
4. Инструменты и электроника продаются втрое дороже расчётной себестоимости —
   но чтобы их делать, придётся поднять всю цепочку: рудник, шахту,
   металлургию. Это и есть главная партия.

## Сословия

| Сословие | Чем живёт | Может уйти на завод |
|---|---|---|
| **Крестьяне** | Земля. Едят своё, излишек несут на рынок | да |
| **Кустари** | Ремесло: еда, одежда, мебель — куда выгоднее | да |
| **Рабочие** | Зарплата на предприятиях | — |
| **Городская беднота** | Услуги: мелкая торговля, подёнщина | да |
| **Средний класс** | Услуги: лавки, ремесло, контора | да |
| **Высший класс** | Услуги и земельная рента с деревни | нет |
| **Солдаты** | Жалованье из казны отдельной статьёй | нет |

Сколько и чего сословие потребляет, определяется его **уровнем жизни** — см.
отдельный раздел ниже. Разбогатевшие крестьяне и кустари не откладывают деньги
мёртвым грузом: они берут больше той же еды, а потом добавляют к столу мясо и
вино.

**Крестьяне** кормятся с земли и потому почти не покупают еду — голода в стране
нет по умолчанию. Урожай гуляет от пейдея к пейдею: то заваливает рынок дешёвой
едой, то заставляет деревню саму идти за покупками.

**Кустари** — те же селяне, взявшиеся за ремесло. Они смотрят на цены и берутся
за то, что выгоднее, но работают несравнимо хуже завода: и выпуск на человека
мал, и сырья на единицу уходит больше. Кустарь — причина, по которой в стране
вообще есть одежда до первой фабрики, и первый, кого фабрика разорит.

**Горожане** не производят ничего вещественного: они заняты торговлей, ремеслом
и искусством, то есть производят «Услуги» — товар, который покупают все
остальные. Отсюда у них постоянный, но плавающий доход, и при этом деньги не
берутся из воздуха. Городские классы отличаются уровнем потребления: высший
потребляет втрое с лишним больше низшего.

**Рабочие** появляются, когда предприятие предлагает больше, чем человек имеет
сейчас. Обратно в деревню хода нет: уклад и навык потеряны. Отсюда и берётся
безработица — долгая незанятость медленно сталкивает рабочего в городскую
бедноту, но не возвращает его в крестьяне.

**Солдаты** — единственное сословие, живущее не с рынка, а из казны: жалованье
им платит государство отдельной статьёй расходов, до всех прочих трат. Оружие
солдат покупает себе сам из этого жалованья, поэтому армия — постоянный
покупатель оружейных заводов. Солдату, которому не заплатили, служить незачем:
он уходит в городскую бедноту.

## Как устроены цены

Это главная механика, поэтому подробно.

У каждого товара есть **якорь** — сглаженная себестоимость производства
(сырьё по текущим ценам плюс труд и содержание) с небольшой нормальной наценкой.
Якорь не константа: подорожало сырьё — подорожал и якорь.

Вокруг якоря цена гуляет в **мягком коридоре** от 55% до 400% себестоимости.
Мягком — потому что вместо грубого обрезания используется насыщение в
логарифмическом пространстве:

```
u = ln(цена / якорь)
u += эластичность × дисбаланс(спрос, предложение)
u  = u_max × tanh(u / u_max)
```

`tanh` даёт ровно то, что нужно от рыночной цены:

* около якоря он почти линеен — цена ходит свободно;
* у границы производная стремится к нулю — чем дальше цена от себестоимости,
  тем труднее продавить её ещё дальше, как и бывает на настоящем рынке;
* границы недостижимы математически — цена никогда не станет нулём и никогда не
  улетит в бесконечность, и при этом нигде нет некрасивой «стенки».

Поэтому хлеб в неурожай честно дорожает втрое, а залежавшаяся мебель падает
ниже себестоимости — но ни один товар не может стоить ни 0.001, ни миллион.

**Товары, которых никто не делает.** У инструментов и электроники нет
фактической себестоимости — их некому считать. Выводить её из собственной цены
нельзя: цена растёт от дефицита, за ней ползёт себестоимость, за ней потолок
коридора, и цена уходит в бесконечность. Поэтому для таких товаров
себестоимость считается **по рецепту**: сырьё по рыночным ценам плюс стоимость
труда. Это опирается только на цены других товаров, никуда не убегает — и
заодно даёт игроку честный ориентир: «если построить цепочку, единица обойдётся
в столько-то, а продаётся втрое дороже».

В интерфейсе коридор показан полоской: серая риска — якорь, точка — текущая
цена. Цвет точки говорит о наценке: зелёный — торгуют в убыток, красный —
сверхприбыль на дефиците.

## Ключевые решения в движке

Несколько мест, где очевидная реализация даёт неправильную экономику. Все они
подробно прокомментированы в коде.

**Цены заморожены внутри пейдея.** Все сделки идут по ценам, объявленным в
начале тика, новые цены считаются в конце. Иначе результат зависел бы от
порядка обхода производителей.

**Выпуск попадает на прилавок следующим пейдеем.** Произведённое сегодня уходит
в «приход» и вливается в склад только в конце тика. Без этого производитель,
обработанный раньше по списку, успевал бы продать товар тем, кто идёт следом.
Исключение — услуги: их оказывают и потребляют сразу.

**Деньги в системе сохраняются.** Товар на рынке остаётся собственностью
владельца — хоть завода, хоть целого сословия, — и выручка начисляется в момент
продажи. Зарплаты, содержание построек и стройка тоже чей-то доход, а не
исчезающие расходы. Проверяется тестом: денежная масса не должна дрейфовать.

**Простой оплачивается не полностью.** Не привезли сырьё — цех стоит, и людей
отправляют по домам. Если платить полную зарплату за простой, завод,
построенный раньше своей сырьевой базы, разоряет владельца за несколько пейдеев.

**Деревня сбавляет выпуск при затоваривании.** Иначе крестьяне везут зерно на
рынок каждый пейдей независимо от того, берут его или нет: склад пухнет до
сотен миллионов, цена ложится на дно коридора, и деревня нищает, продолжая
работать в пустоту.

**Своё съеденное засчитывается.** Крестьянин, ни разу не зашедший в лавку,
сыт — и в расчёте довольства это учитывается. Без такой поправки самое
благополучное сословие числилось бы голодающим.

**Эффект богатства.** Норма потребления — минимум, а не потолок. Если этого не
учесть, доходы сверх нормы копятся мёртвым грузом, выручка производителей
оказывается меньше выплаченных доходов, и весь частный бизнес живёт в убыток.
Отсюда вырос весь механизм уровня жизни (см. ниже).

**Роскоши нужна бронь в бюджете.** Строгий приоритет ступеней («сначала всё
необходимое, роскошь на сдачу») означает, что роскошь не купят никогда:
обычная корзина в этой экономике дороже, чем люди могут себе позволить, и
сдачи не остаётся. Поэтому, когда роскошь уже вошла в привычку, под неё
бронируется доля бюджета — но только после еды. От вина отказываются не в
пользу хлеба, а в пользу новых инструментов.

**Налоги возвращаются в оборот.** Госрасходы отдают часть казны населению. Без
этого канала налоги высасывают деньги из экономики и начинается дефляционная
спираль.

**За цех платит его хозяин.** Владельца предприятия приходится нести в плане
производства явно, а не брать из переменной цикла планирования. Иначе расходы
всех заводов страны списываются с того, кто оказался последним в обходе, — и
чужие убытки уводят в минус ни в чём не повинного игрока. Заметно это
становится только когда в одной стране заводы у двоих и больше.

**Склад — по стране, а не по игроку.** См. раздел про иностранные инвестиции:
общий склад отнимал бы у иностранного завода непроданный товар каждый пейдей.

**Себестоимость простоя ограничена рецептом.** Цех, которому не подвезли
сырьё, платит зарплату полностью, а выпускает почти ничего. Делить одно на
другое буквально нельзя: при выпуске в сотые доли единицы «себестоимость»
уходит в миллионы, за ней ползёт якорь, за якорем цена — и область улетает в
гиперинфляцию на ровном месте. Рецептурная оценка от цен на сырьё и труд
никуда не убегает и служит потолком здравого смысла. С переездом рынков в
области это стало критично: рационирование сырья теперь идёт по каждой области
отдельно, и почти нулевой выпуск случается куда чаще.

**Война уничтожает деньги и людей, а не перекладывает их.** Разграбленная казна
и сбережения погибших исчезают из системы — это единственное место в игре, где
денежная масса законно проседает. Проверка баланса это учитывает.

## Уровень жизни

Потребление меряется не «наелся / не наелся», а одним комплексным показателем —
**уровнем жизни**. Это безразмерная величина вокруг единицы: во сколько раз
сословие позволило себе больше своей обычной корзины.

| Уровень | Как живут |
|---|---|
| ниже 0.75 | недоедают, довольство падает |
| ~1.0 | живут как положено: еда, одежда, обстановка, услуги |
| 1.1 и выше | появляется выбор — и начинается роскошь |

Мера относительная и потому самонастраивающаяся: эталон считается по **якорным**
ценам текущего пейдея, так что от одной лишь инфляции уровень жизни не
двигается — человек ест ровно то же самое.

**Ожидания.** У каждого сословия есть уровень, который оно считает для себя
нормальным. Ожидания растит достаток: у кого на счетах лежит много корзин, тот
начинает считать нормой жить лучше. Меняются они медленно и вниз идут ещё
неохотнее, чем вверх — привычка к достатку въедается, отвыкать от неё больно.

Ожидание работает двояко. Во-первых, это множитель обычной корзины: разбогатев,
крестьянин просто берёт больше той же еды и одежды. Во-вторых, оно открывает
**лестницу роскоши** — каждая ступень включается на своём уровне ожиданий:

| Ожидания | Что появляется на столе |
|---|---|
| 1.10 | **Мясо** |
| 1.25 | **Вино** |
| 1.40 | **Роскошная одежда** |
| 1.55 | **Роскошная мебель** |
| 1.70 | **Роскошные услуги** — опера, салоны, галереи |

Всё это — новые товары и новые отрасли: скотоводческая ферма, винодельня,
ателье, мебельная мануфактура. Роскошные услуги производит **оперный театр** —
административное здание, которое, в отличие от ратуши, ещё и выпускает товар.
Строит его только государство, и это единственный их источник: оперу нельзя ни
завезти из-за границы (услуга не хранится), ни сделать кустарно.

**Зачем это лидеру.** Сытое общество и довольнее, и терпеливее: высокий уровень
жизни прибавляет к довольству напрямую и заметно смягчает удары — безработицу и
мобилизацию. Отсюда прямое следствие: **чем лучше живут люди, тем больше солдат
можно поставить под ружьё**, потому что потолок доли армии в населении растёт
вместе с достатком. Богатая страна воюет не только лучшим оружием, но и большей
армией.

## Банкротство и субсидии

Предприятия работают в долг: зарплаты и сырьё оплачиваются и в минус, пока касса
владельца не упёрлась в **порог банкротства**, который устанавливает само
государство отдельным полем в экономическом курсе.

Когда кредит исчерпан, дело признаётся банкротом и встаёт целиком — на пустой
кассе не нанять людей, чтобы заработать на найм людей. Выбраться можно двумя
путями: распродать товар и снести убыточное самому либо получить **субсидию** из
казны. Лидер видит всех промышленников страны в списке граждан — с кассой,
капиталом, числом рабочих и подсказкой, сколько не хватает до выхода из ямы, —
и выдаёт деньги прямо на счёт.

Чтобы дело не мигало «банкрот / не банкрот» каждый пейдей, дёргая занятость
всего города, выход требует подняться заметно выше порога.

## Вотум доверия

Между выборами граждане-промышленники в любой момент могут выразить лидеру
доверие или недоверие — двумя кнопками. Как только недоверие набирает больше
половины голосов (**50% + 1** от всех граждан-игроков, а не от
проголосовавших), лидер немедленно смещается и назначаются **внеочередные
выборы**.

Считать от проголосовавших нельзя намеренно: иначе двое недовольных из двадцати
свергали бы лидера просто потому, что остальные промолчали. Голос можно менять
когда угодно, он держится до ближайших выборов, а новый лидер начинает с чистого
листа.

## Иностранные инвестиции

Лидер может открыть страну для чужих промышленников. Дальше работает простое
правило: **товар идёт на местный рынок, прибыль — владельцу**.

Завод иностранца стоит в чужой стране, значит, нанимает тамошних рабочих по
тамошнему МРОТ, покупает сырьё по тамошним ценам и выкладывает выпуск на
тамошний прилавок — его покупают местные жители за местные деньги. Выручка при
этом уходит владельцу за границу, налог на прибыль платится стране, где стоит
завод.

Технически это значит, что склад игрока хранится **отдельно по каждой стране**
(`Player.warehouses`). Общий склад здесь не годится: рынок страны-хозяйки в
конце пейдея переписывает остатки своих торговцев, и непроданный товар
иностранного завода исчезал бы вместе с вложенными в него деньгами.

Во врага вкладываться нельзя: пока идёт война, стройка в стране противника
запрещена.

## Области: у каждой свой рынок

Государство — это **набор областей**, а не точка на карте. У каждой области
свой рынок со своими ценами, своим складом и своим дефицитом, своё население,
своя рабочая сила и своё довольство. На старте у каждой страны по две области —
столичная и провинция.

Область — основная единица карты и войны. Захваченная область **не исчезает**:
она остаётся на месте, меняет цвет владельца, и сосед может отбить её обратно.
Государство пропадает с политической карты, только когда у него не остаётся ни
одной области, — но сами области никуда не деваются.

Переключатель областей есть на всех витринах: рынок, население, строительство.
Смотреть «среднюю температуру по стране» бессмысленно — в соседней области
хлеб может стоить вдвое дороже, и это и есть повод туда что-нибудь построить.

## Торговля

Торговля работает **всегда**, даже без единой торговой площади: обозы ходили и
до всякой биржи. У каждой области есть базовая пропускная способность, а
«Торговая площадь» её увеличивает — в этом её смысл, а не в том, чтобы открыть
границу с нуля.

Обмен идёт на двух уровнях:

* **Внутри страны** — казна скупает излишек там, где дёшево, и выкладывает на
  прилавок там, где дорого. Это выравнивает цены между областями и приносит
  казне разницу.
* **Между странами** — мировой рынок, где торгуют именно области, а не страны.
  Вывозить выгодно оттуда, где дёшево, даже если в соседней области той же
  страны дорого.

## Международная биржа

Вкладка **Биржа** показывает мировой рынок целиком: мировую цену каждого товара,
котировки всех двадцати государств, у кого дешевле и у кого дороже, и обе
стороны каждой сделки прошлого пейдея — кто вывез, кто ввёз, сколько досталось
казне пошлиной.

Мир замкнут: двадцать областей и составляют его целиком, поэтому вывезенный
товар обязан быть кем-то куплен — внешнего покупателя из ниоткуда нет. Продаёт
страна, где дома дешевле мировой цены, покупает та, где дороже и не хватает.
Объём с обеих сторон ограничен уровнями «Торговых площадей»: без них граница
закрыта и разница цен между странами держится сколько угодно долго. Это и есть
главный смысл биржи для игрока — видеть, где ваш товар стоит вдвое дороже, чем
у вас дома.

## Оружейная промышленность

| Отрасль | Выпуск | Сырьё |
|---|---|---|
| **Серный рудник** | Сера | — |
| **Оружейный завод** | Оружие | сталь ×2, лес ×1 |
| **Снарядный завод** | Снаряды | сталь ×1, сера ×2 |

Обе военные отрасли сидят на стали, поэтому воевать всерьёз может лишь страна,
поднявшая всю цепочку от руды и угля. Покупателей у них двое и они разные:

* **оружие** покупают сами солдаты из своего жалованья — оно изнашивается и
  теряется, поэтому спрос идёт каждый пейдей и растёт вместе с армией;
* **снаряды** закупает казна на армейские склады, до целевого резерва на
  солдата. В бою они расходуются, и пополнять запас приходится снова.

Толпа без оружия и снарядов почти ничего не стоит: боевая сила армии — это её
численность, помноженная на вооружённость, снабжение и боевой дух. Армия в
миллион голых людей проиграет вдесятеро меньшей, но вооружённой.

## Война

Войну объявляет лидер государства и только **соседу по карте** — воевать можно
лишь через общую границу. Союзники обеих сторон втягиваются немедленно.

Каждый пейдей на каждом фронте идёт бой. Силы сторон умножаются на военную
удачу, и обе стороны несут потери в областях, где идут битвы:

* **армия** — убыль тем больше, чем сильнее противник;
* **мирное население** — гибнет вместе со своими сбережениями;
* **промышленность** — уровни предприятий выбиваются из строя. Они не сносятся
  насовсем: разрушенный уровень не даёт ни рабочих мест, ни выпуска, пока его
  не починят. Кнопка «Починить» есть у каждого пострадавшего предприятия;
  казённое чинит казна, частное — сам владелец из своего кармана;
* **казна** — часть её уничтожается и разграбляется.

Перевес в боях копится в **оккупацию**. Когда она доходит до конца, область
переходит победителю вместе с населением и заводами. Государство, потерявшее
все области, прекращает существование: его казна, склады и граждане отходят
победителю, а границы на карте перестраиваются.

**Судьба промышленников на занятой земле.** Заводы вместе с землёй не
отбирают — они остаются за своими хозяевами, которые оказываются иностранцами в
чужой теперь стране. Что с ними делать, решает лидер-победитель: во вкладке
«Война» он видит список этих промышленников с их предприятиями и числом рабочих
и по каждому нажимает **«Оставить»** или **«Снести»**. Есть и общие кнопки —
оставить всех или снести всё разом.

*Оставить* — хозяин продолжает работать и платить налоги уже вам. *Снести* —
его заводы в этой области уничтожаются, а владельцу возвращается лишь малая
часть вложенного: имущество уходит наспех и наполовину разграбленным. На
решение даётся несколько пейдеев; не успели — промышленников оставляют в деле,
потому что захват и без того разорителен, чтобы вдобавок сносить работающие
заводы по недосмотру.

**Фронт идёт по областям.** Воюют армии государств, но бои разворачиваются на
конкретных парах смежных областей, и разоряются именно они — тыл живёт своей
жизнью. Силы страны делятся между её фронтами: на два направления сразу армии
хватает хуже, чем на одно. Оккупация копится на конкретную область — её и
займут.

**Мобилизация.** Лидер может собрать армию не деньгами, а приказом. Мобилизация
выгребает людей случайными долями по сословиям и городам — в том числе рабочих
прямо с заводов, отчего промышленность проседает, — и не смотрит, выгодна ли
человеку служба. Платой служит падение довольства по всей стране на всё время
мобилизации.

## Мятежи и гражданская война

Нищая область копит **озлобление**. Когда довольство падает ниже порога и
держится там, вспыхивает **бунт**: жгут заводы (уровни выходят из строя, как на
войне), гибнут люди, производство падает почти вдвое, казна тратится на
усмирение.

Если бунт не унять достаточно долго, из него вырастает **гражданская война**:
область откалывается, провозглашает собственное государство, забирает часть
армии и казны — и метрополия немедленно оказывается с ней в состоянии войны.
Отбивать её придётся так же, как чужую.

Единственное лекарство — уровень жизни. Нужда бьёт по довольству сильнее, чем
радует достаток: привыкнуть к хорошему легко, терпеть нищету тяжело.

## Дипломатия

* **Союз.** Предложение, которое надо принять. Союзники автоматически
  втягиваются в войны друг друга. AI-государства соглашаются на союз, если не
  воюют с вами.
* **Сепаратный мир.** Стороны войны — списки, а не пара стран, и мир
  заключается **парой**. Союзник, которому война надоела, перестаёт воевать со
  своим противником и выходит из войны, а его товарищи продолжают: фронт между
  ними никуда не делся. Из войны страна выпадает только тогда, когда помирилась
  со всеми своими противниками. AI соглашается на мир, если проигрывает или
  если война затянулась.

## Государство

Первый зарегистрировавшийся игрок получает полномочия гос.деятеля. Ему доступны:

* **Налоги и курс** — на прибыль, с продаж, подоходный, доля госрасходов,
  земельная рента, МРОТ и порог банкротства.
* **Субсидии промышленникам** — список граждан с их кассой и состоянием дел;
  разорившихся можно вытащить прямой выплатой из казны.
* **Государственные предприятия** — строятся за счёт казны, прибыль возвращается
  в казну, кассовые разрывы она закрывает сама.
* **Административные здания** — ратуша, торговая палата, академия. Ничего не
  производят: содержат служащих и создают спрос на еду и мебель. Пока это задел:
  торговая палата предназначена под внешнюю торговлю, академия — под технологии.
* **Военный бюджет** — твёрдая сумма из доходов казны за пейдей и ставка
  жалованья солдату. Численность армии из них и выводится: `бюджет ÷ ставка`,
  и ни человеком больше. Отдельного ползунка «сколько солдат» нет намеренно —
  иначе казну можно было бы увести в минус одним движением, призвав всех
  подряд. Солдаты сверх бюджета остаются без жалованья и расходятся сами.
* **Война, мобилизация и дипломатия** — объявление войны соседям, предложения
  мира и союза (см. выше).

## Проверка баланса

```bash
python balance_test.py 250 --player --trade --war
```

Гоняет 250 пейдеев и проверяет двадцать одно условие: цены в коридоре, страна
сыта, крестьяне не разорены, денежная масса сошлась.

| Флаг | Что добавляет |
|---|---|
| `--player` | бот-промышленник: может ли игрок нанять людей, построить цепочку и выйти в плюс, ни разу не провалившись в долги |
| `--trade` | три государства строят торговые площади и торгуют: мировой рынок обязан быть замкнутым по товару и по деньгам |
| `--war` | два соседа поднимают оружейную цепочку и воюют, третий входит союзником и выходит сепаратным миром: проверяется, что бои идут, промышленность получает урон, области меняют хозяина и не теряются с карты |

```bash
python tools/design_check.py
```

Считает стартовое равновесие: хватает ли крестьян прокормить страну, сколько
кустари дают одежды против спроса, сходятся ли доходы горожан с их
потреблением. Пригодится при правках баланса — все «ручки» в `app/config.py`.

## Структура

```
run.py                    запуск
balance_test.py           прогон экономики без сервера + проверки
tools/design_check.py     расчёт стартового равновесия
app/
    config.py             все параметры баланса
    models.py             состояние мира (dataclass-объекты)
    db.py                 SQLite: снимок мира + история для графиков
    auth.py               пароли (PBKDF2) и токены
    api.py                игровое API — чистые функции над миром
    main.py               HTTP-сервер и планировщик пейдеев
    economy/
        pricing.py        мягкий ценовой коридор
        society.py        сословия: деревня, ремесло, услуги, мобильность
        engine.py         тик: труд, производство, потребление, цены, общество
        seed.py           начальный доиндустриальный мир
    static/               интерфейс (HTML + CSS + ванильный JS)
```

## Что дальше

* **Технологии.** Академия ждёт своей механики: `output_per_worker` —
  параметр отрасли, его естественно сделать растущим за вложения.
* **Война по инициативе AI.** Сейчас войну объявляет только живой лидер;
  AI-государства умеют лишь обороняться, соглашаться на мир и вступать в союзы.
* **Флот и укрепления.** Бой считается по одному числу боевой силы — есть куда
  добавить роды войск и оборонительный бонус.
* **Кредиты под процент.** Работа в долг и банкротство уже есть, спасают пока
  только субсидии из казны — не хватает банков и займов.
* **Профсоюзы и волнения.** Довольство по сословиям уже считается отдельно;
  недовольные рабочие — готовая почва для забастовок.
* **Логистика.** Обозы возят товар мгновенно и без потерь. Транспортное плечо,
  дороги и порча в пути сделали бы географию по-настоящему значимой.
